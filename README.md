# Nu•Dee pomodoro · birthday edition 🐭🌧️💙 created by Claude AI fellow🦾🤖🦿

ตัวจับเวลา Pomodoro คาเฟ่จิ๋ววันฝนตก ทำขึ้นเป็นของขวัญวันเกิดให้ Nu•Dee (limited 1 of 1)
ภาพ เสียง และเพลงทั้งหมดสร้างด้วยโค้ด ติดตั้งลงมือถือเป็นแอปได้ และใช้ออฟไลน์ได้

- **การเดินทาง:** คาเฟ่ลอยผ่าน 4 เมืองตาม session ที่ทำเสร็จ คือเมืองฝน → เมืองนีออน → เมืองซากุระ → หมู่บ้านหิมะ แล้วไปถึงงานปาร์ตี้วันเกิดตอน long break
- **focus:** กลางคืน ไฟจากตึกและบ้านเรือนส่องออกมา หนูชมพูอ่านหนังสือหรือถักผ้าพันคอสีฟ้า
- **พัก:** คาเฟ่จอดแวะ แดดของเมืองนั้นสาดเข้ามาในห้อง (แต่ละเมืองแสงสีไม่เหมือนกัน)
- **ของที่ระลึก:** ผ่านแต่ละเมือง ของตกแต่งจากเมืองนั้นจะผุดขึ้นในห้อง (ร่ม, ชุดเกราะไฮเทคกับหน้าต่างอัจฉริยะ, โคม แจกันซากุระ และดาบต้องสาปในฝัก, ลูกแก้วหิมะ, ปาร์ตี้) และหมู่บ้านหิมะตอนกลางคืนมีแสงเหนือ เริ่มรอบใหม่ห้องก็กลับเป็นเหมือนเดิม
- **เสียง:** ฝนนุ่มๆ ฟังสบาย เสียงประจำแต่ละเมือง เพลง lo-fi เปียโนไฟฟ้า กล่องดนตรี Happy Birthday ตอนถึงงานปาร์ตี้ และเสียงตอนกดปุ่ม

## เอาขึ้นเว็บแล้วติดตั้งลงมือถือ

1. สร้าง repository ใหม่บน GitHub แล้วกด **uploading an existing file**
2. แตก zip แล้วลาก **ไฟล์และโฟลเดอร์ข้างใน** ทั้งหมดไปวาง แล้วกด **Commit changes**
3. **Settings → Pages** เลือก Branch `main` / `(root)` แล้ว **Save** รอ 1–2 นาทีจะได้ลิงก์
4. ส่งลิงก์ให้ Nu•Dee
   **iPhone:** เปิดใน Safari → Share → **Add to Home Screen**
   **Android:** เปิดใน Chrome → ปุ่ม **install app** มุมซ้ายบน หรือเมนู ⋮ → Add to Home screen

(หรือใช้ Netlify Drop: app.netlify.com/drop ลากโฟลเดอร์ไปวาง)
